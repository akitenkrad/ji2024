# 可視化

Python パッケージ `srap-tools` (モジュール `srap_tools`) が Rust の出力から図を生成する．workspace ルートで `uv sync` してインストールし，`uv run srap-tools <subcommand>` で実行する．

## `visualize` — 単一実行

`runvault path --latest --subcommand run` で `run` の親 run を解決し (`--results_dir` を渡せばそれを使う)，試行ごとの子 run の `metrics.csv` を読んで旧 `(run, round, …)` の表に組み直し，ラウンドごとに試行平均を取る．

```bash
uv run srap-tools visualize
uv run srap-tools visualize --results_dir results/20260525_120000   # legacy も可
```

出力 `<results-root>/srap-allocation/figures/<run_slug>/` (run ディレクトリの外．`manifest.csv` は `finish()` が確定させるので，後から描いた図はハッシュを持たない):

- `welfare_timeseries.png` — SW と Avg r_size のラウンド推移 (満足度)．
- `fairness_timeseries.png` — Gini と F(V,NV) のラウンド推移 (公平性)．
- `final_metrics.png` — 最終ラウンドの指標サマリ (棒グラフ)．

## `visualize-sweep` — sweep / POA

スイープ親 run の試行子 run (または `poa` run の世代パネル) を読む．`--sweep_dir` にディレクトリを渡すか，省略時は `--subcommand sweep|poa` で `runvault path --latest` が返す run を選ぶ．

```bash
uv run srap-tools visualize-sweep
uv run srap-tools visualize-sweep --subcommand poa
uv run srap-tools visualize-sweep --sweep_dir results/20260525_120000_sweep   # legacy も可
```

出力 (存在する CSV に応じて):

- `sweep_sw_by_subset.png` — 資源サブセット別の平均 SW を入室条件で色分け (r_size > r_random の順序は seed を揃えた比較で最も明瞭; [再現](reproduction.ja.md) 参照)．
- `poa_convergence.png` — POA の最良/平均適応度の世代推移 (Fig.4 風; エリート保存で最良は単調非減少)．

## `show-experiment-settings`

run の `parameters` (`config.json`)・`llm` ブロック・run スコープの LLM 指標を表示する — 旧 `llm_meta.json` はこの 2 箇所に分かれた．`--results-dir` でディレクトリを指定でき (legacy な flat `config.json` / `sweep_config.json` / `poa_config.json` / `llm_meta.json` も読める)，`--subcommand` で `--latest` が返す run を選び，`--json` で JSON 出力する．

## `reproduce`

`reproduce` の run を読む — Table 2 のセルと POA のパネルは `events.jsonl`，判定は `artifacts/reproduce_summary.json`．観測 vs 論文の照合を再表示し，`table2_sw_by_policy.png` (ポリシー別社会的厚生の棒グラフ) と `fig4_poa_convergence.png` (POA 適応度収束) を figures ディレクトリへ書き出す．`--results-dir` でディレクトリを指定でき，省略時は最新の `reproduce` run を使う．`initial_fitness` は記録に無い (世代 0 の `best_fitness` そのもの) ので，表示側が世代パネルから補う．

## run の解決

`runvault path` は `$RUNVAULT`，無ければ PATH 上の `runvault` を使う．インストールしていない場合は `export RUNVAULT=<rs-runvault>/target/debug/runvault` を設定するか，run ディレクトリを直接渡す．
